Privacy policy

Last updated: 2 November 2026

PrivateGmail is a personal tool used only by its owner, Lin Li, to access their own Gmail account.

What data it accesses

With the owner's consent through Google's sign-in, PrivateGmail can read, draft, send, label and organize email in the owner's own Gmail account.

How data is used

Email data is used only to carry out the owner's own requests, such as summarizing or replying to messages. It is not sold, shared with third parties for advertising, or used to build profiles.

Storage

Sign-in tokens are stored encrypted on the owner's own computer. PrivateGmail runs no server and keeps no copy of email data.

Google API Services User Data Policy

PrivateGmail's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
